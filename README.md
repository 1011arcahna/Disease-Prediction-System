# Disease Prediction System

This project is a **Machine Learning–based web application** designed to predict the likelihood of various diseases using health and lifestyle parameters. It provides users with actionable insights based on key indicators such as BMI, glucose levels, cholesterol, and other lifestyle factors.

## Technologies Used
- Python
- Scikit-learn
- Flask
- Streamlit
- Pandas, NumPy
- Matplotlib, Seaborn

## Features
- Implements **Random Forest Classifier** achieving ~95% accuracy on test data.
- Provides **real-time predictions** via a Flask backend integrated with a Streamlit frontend.
- Visualizes trends and analytics using **heatmaps, radar charts, and lifestyle analytics**.
- User-friendly interface to input health parameters and get instant results.

## Purpose
The system aims to help individuals understand potential health risks early and make informed decisions to improve their well-being. It also demonstrates the integration of **data preprocessing, visualization, machine learning modeling, and web deployment** in a single project.

## How to Run
1. Clone this repository.
2. Install required dependencies: `pip install -r requirements.txt`.
3. Run the Flask app: `python app.py`.
4. Access the application in your browser at `http://localhost:5000`.
